# Implementation Status (Code vs Specs)

Snapshot of how the current codebase aligns to the spec docs. Organised by spec file with `Implemented / Partial / Missing` notes and key references.

## 00–04: Overview, Progression, Combat, Risk, Economy
- **00-overview**: Foundations present (classless/skills, risk zones, regional banking), but many systems are Lua scaffolds without core/client enforcement.
- **01-progression**: Implemented XP-disable and derived level (skills/48, caps 1–25) and stat caps (150/400) in C++ (`src/MortalOverhaul.cpp`, `src/MortalLevel.cpp`, `src/ScriptMgr.cpp`); skill schema/cache in `sql/01_create_tables.sql`. Partial: skill gain loops are Lua (`lua/combat_skills.lua`, `lua/gathering_skills.lua`), mastery trees Lua/SQL only (`lua/mastery_trees.lua`, `sql/52_mastery_trees.sql`); hunger/encumbrance Lua-only. Missing: mentor/free respec logic, C++ enforcement for hunger/encumbrance, prepared statements not wired into core enums.
- **02-combat**: Custom player damage/hit/crit and HP/Mana/energy formulas hooked (`src/MortalCombat.cpp`, `src/ScriptMgr.cpp`); brace mechanic via Lua + C++ (`lua/brace_mechanic.lua`, `src/MortalOverhaul.cpp`); quest XP→gold and mailbox item blocking live. Partial: crime/outlaw/bounty mostly Lua/DB (`lua/outlaw_state.lua`, `lua/bounty_board.lua`); C++ bounty map is stub; friendly-fire/red-zone logic in Lua. Missing: spell coeff rewrites, creature→player tuning, consistent non-player damage path.
- **03-risk-zones**: Zone PvP/loot, criminal flags, corpse chest flow in Lua + DB (`lua/zone_pvp_system.lua`, `sql/38_zone_pvp_config.sql`, `sql/99_custom_corpse_chest.sql`); border grace in `lua/border_grace_window.lua`. Added: C++ zone-risk cache and zone-change tracking (`src/MortalOverhaul.cpp`, `src/ScriptMgr.cpp`), PvP bag-drop with overflow to killer via mail (no chest), and simple Green-zone outlaw KOS. Partial: signage/client cues still missing.
- **04-economy**: Regional banking schema + Lua (`sql/01_create_tables.sql`, `lua/regional_banking.lua`); mail items blocked and AH→regional bank redirect (`src/ScriptMgr.cpp`). Partial: market stalls/courier/black-market/resource rotation/seasonal events/caravans Lua+SQL scaffolds (`lua/market_stalls.lua`, `lua/courier_contracts.lua`, `lua/caravan_system.lua`, `sql/27_market_district_kiosks.sql`, `sql/28_courier_contracts.sql`, `sql/73_caravan_upgrades.sql`); crafting blueprint economy present but C++ item mutation stubbed. - **08-guilds-sovereignty**: Territory/stronghold/war in Lua (`lua/guild_territory.lua`, `lua/stronghold_system.lua`, `lua/siege_window.lua`, `lua/siege_tech.lua`) with DB (`sql/31_territory_control_points.sql`, `sql/79_mortal_strongholds.sql`, `sql/60_guild_wars.sql`). Partial: no core enforcement for vulnerability windows/guards/spawns, no seasonal reset/ranking in core. Missing: siege destructibility and alliance/politics beyond DB rows.
- **13-caravans-contracts**: Courier/contracts/ambush/wagon stats in Lua (`lua/courier_contracts.lua`, `lua/caravan_system.lua`, `lua/caravan_movement.lua`, `lua/ambush_spawner.lua`) with DB (`sql/28_courier_contracts.sql`, `sql/75_caravan_wagon_stats.sql`, `sql/76_contract_crates.sql`).
