## How to Update

Run the verification script:
```bash
python3 scripts/verify_all_specs.py
```

This will:
1. Check all spec files in `docs/specs/`
2. Verify required Lua files exist in `lua/`
3. Verify required C++ files exist in `src/`
4. Verify required SQL tables exist in `sql/`
5. Check for event hooks and integration
6. Generate `SPEC_VERIFICATION_REPORT.json` (detailed data)
7. Update `SPEC_VERIFICATION_ACCURATE.md` (human-readable)
