# Mortal Warcraft - Approved Embeddable Addons List

## Purpose

This document provides a comprehensive list of approved WoW 3.3.5a addons that can be embedded or recommended for Mortal Warcraft. Addons are categorized based on:
- Spec 101 (Addon Policy) - Allowed/Banned/Grey Area
- Spec 15 (UI Client) - Already planned addons
- Embeddability via AIO vs separate installation
- Compatibility with Mortal systems

**Last Updated:** 2025-01-XX

## ❌ Banned Addons (Red Line - Forbidden)

These addons are **explicitly forbidden**. Using them can result in warnings, suspensions, or bans.

### Combat Automation

- One-button rotation scripts
- Auto-interrupt addons
- Auto-CC addons
- Auto-heal logic that chooses targets
- Addons that automatically target enemies
- Addons that cycle abilities automatically

### Radar / ESP / Visibility Hacks

- Addons that show hidden units beyond normal API
- Addons that reveal stealthed players beyond visual shimmer
- "Player radar" addons showing exact positions in Red Zones
- ESP (Extra Sensory Perception) addons

### Navigation / Fog-of-War Cheats

- Addons that rebuild full enemy movements in Red Zones
- Addons that circumvent "no party dots in Red Zones"
- Addons that break war fog mechanics
- Addons that show full map in Red Zones

### Hyper-Automated Trading

- Mass-posting Auction House bots
- Auto-undercutting scripts
- Market scanning and reaction scripts
- Mail/trade API abuse scripts

## Embedding Methods

### Method 1: Separate Installation (Standard)

**For:** Most addons  
**Process:**
1. Download addon
2. Extract to `WoW/Interface/AddOns/`
3. Enable in character select screen
4. Configure in-game

**Used For:**
- MortalUI core addon
- All wrapped addons (Immersion, Bagnon, etc.)
- Player-installed addons

### Method 2: AIO Embedding (Server-Driven)

**For:** Custom Mortal UI panels  
**Process:**
1. Server-side Lua script defines UI
2. AIO sends UI code to client
3. Client renders UI using WoW API
4. User actions sent back to server

**Used For:**
- Task board UI
- Warfront signup UI
- Admin control panels
- Market stall UI
- Bounty board UI

**Advantages:**
- No client modification needed
- Server controls UI logic
- Secure (server validates actions)
- Easy updates (server-side only)

### Method 3: Launcher Installation (Automated)

**For:** Mortal Addon Pack  
**Process:**
1. Launcher downloads addon pack
2. Extracts to `WoW/Interface/AddOns/`
3. Verifies hashes
4. Applies Mortal configurations
5. Updates on launch

**Used For:**
- Official Mortal Addon Pack
- MortalUI and dependencies
- Pre-configured addons

## Compatibility Notes

### WoW 3.3.5a Compatibility

- ✅ **Tested:** All addons in "Approved" section are known to work with 3.3.5a
- ⚠️ **Check Version:** Some addons may need specific 3.3.5a versions
- ❌ **Not Compatible:** Retail addons (8.0+) will not work

### AzerothCore Compatibility

- ✅ **Compatible:** All addons work with AzerothCore 3.3.5a
- ✅ **AIO Compatible:** Server-driven UI uses AIO (mod-aio)
- ✅ **ALE Compatible:** Lua scripts use ALE (mod-eluna)

### Mortal System Compatibility

- ✅ **Compatible:** Addons that only display information
- ⚠️ **May Conflict:** Addons that modify game mechanics
- ❌ **Incompatible:** Addons that automate gameplay

## Enforcement

### Technical Limits

WoW's client API already protects:
- Addons cannot cast spells without hardware event
- Addons cannot move characters
- Addons cannot accept popups automatically

### Server-Side Detection

We monitor for:
- Abnormal behavior (perfect timing, impossible reactions)
- Suspicious movement or targeting patterns
- Botting-like behavior

### MortalUI Enforcement

MortalUI may enforce:
- Minimum nameplate visibility
- Enemy cast bar visibility
- Combat text essentials
- No extreme zoom hacks
- No visibility cheats

## Player FAQ

### "Can I use addons not on this list?"

**Answer:** Yes, if they follow the addon policy (Spec 101):
- No automation
- No ESP/radar
- No fog-of-war breaking
- Only display information you already have

### "Will you support my favorite addon?"

**Answer:** We support the Mortal Addon Pack. Other addons are "use at your own risk" but we'll help troubleshoot if it follows policy.

### "Can I write my own addon?"

**Answer:** Yes, as long as:
- Uses only data we expose (MortalUI comm channels)
- Doesn't reverse-engineer hidden information
- Follows addon policy rules

### "What if an addon gets banned?"

**Answer:** We will:
1. Announce on Discord & website
2. Update this document
3. Give grace period (except extreme cases)
